# 泰语 84 天学习计划

单文件网页，包含三部分：84 天学习计划与打卡、76 条可点读泰语短语、声调规则速查。

- 每天 2 小时，共 12 周 / 84 天 / 168 小时
- 高频优先排序，目标为「跟泰国女友沟通 + 在泰国生活」
- 打卡进度保存在浏览器 localStorage（key: `thai84d-v1`），换设备不迁移

## 使用

直接用浏览器打开 `index.html` 即可，**推荐 Microsoft Edge**——Edge 自带泰语 Natural 在线语音，点短语能立即发音；其他浏览器可能没有泰语语音。

顶部三个标签：

| 标签 | 内容 |
|---|---|
| 计划与打卡 | 12 周主题、每日时间分配、84 天勾选清单、阶段自检、综合达标线 |
| 短语本 · 点读 | 76 条短语，点行朗读；`S` 按钮复制并打开 speecher.org |
| 规则速查 | 五声调、活/死音节判定表、三步判定法、两个例外 |

## 发音

- 点任意一行由浏览器语音合成朗读（`speechSynthesis`，`lang=th-TH`）
- 若要 MP3 下载，用行尾 `S` 按钮走 speecher.org（该站不支持 URL 传参，需粘贴后播放）
